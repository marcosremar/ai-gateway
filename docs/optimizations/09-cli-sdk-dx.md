# CLI, SDK & Developer Experience — 100 Optimizations (IDs 801-900)

> This audit covers the `ai-gateway` CLI (`bin/ai-gateway.ts`, 7949 lines, manual switch/case), the cost-audit binary, the SnapGPU Python CLI (`cli/main.py`), three divergent HTTP SDK clients (`src/sdk/client.ts`, `sdk/node/index.ts`, `sdk/python/gateway_sdk/client.py`), the publishable library entry points (`src/index.ts`, `tsup.config.ts`, `package.json`), error/contract types, and developer docs. The dominant theme is **drift and inconsistency**: three SDKs with different method names, defaults, and return shapes; a duplicate `src/` vs `src/modules/` tree that breaks tree-shaking and confuses the public surface; README/package naming mismatch (`@ai-gateway/*` docs vs `@parle/ai-gateway` package); and uneven CLI ergonomics (only ~8 of ~30 commands support `--json`, usage errors share exit code 1 with runtime errors). On the **Cost** side, the primary `gpu deploy` path never surfaces an estimate or a cost ceiling before spending, while balance/spend is only shown opportunistically. Items below are grouped into 8 sub-themes; Usability is weighted heaviest, with Cost, Reliability, and Functionality woven throughout.
