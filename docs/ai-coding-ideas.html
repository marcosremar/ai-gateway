Expert AI-Coding Workflow

Distilled from Karpathy / Willison / Osmani / Anthropic 2026 report. Mirrored in CLAUDE.md.

  1. Spec before code — generate spec.md (requirements + edge cases) first.
  2. Plan as meta-program — step list saved, agent executes one per turn.
  3. Stuff full context — ADRs, files, errors, doc excerpts upfront. Context > prompt cleverness.
  4. One concrete change per turn — land it, verify, commit, next.
  5. Trade-offs first, code second — pros/cons of A vs B before implementation.
  6. Function signatures explicit — agent fills body. Reduces drift.
  7. Test alongside, never after — test plan in spec, run after each step.
  8. Commit granular — each step = one commit. Rollback granularity = recovery speed.
  9. Reset stuck threads — fresh conversation when looping/contradicting.
  10. Review every line — ~45% AI code carries vulns; assume bug present.
  11. Never merge what you cannot explain — defend in review or do not ship.
  12. Prompt-in-PR — include generating prompt in PR description.
