Smart Turn Detection — How it works

ML-based end-of-turn detection. Replaces dumb silence-threshold pauseMs with a model that asks: "Did the user actually finish, or just pause to think?". Source analyzed: pipecat-ai/pipecat v3 ONNX model + HTTP variant.

1. Problem: silence ≠ done

Current ai-gateway /v1/stt/stream uses pauseMs: wait N ms of silence → end turn → fire LLM. This breaks on natural speech.

❌ Silence-threshold (current)

  • "Send a message to..." [pause 800ms thinking] — bot interrupts before name spoken
  • Drop pauseMs to 300ms → bot cuts every word
  • Raise pauseMs to 1500ms → laggy, conversation feels dead
  • One global value for all utterance shapes
  • Trailing "uhhh" counts as speech, blocks turn end

✅ Smart Turn (ML)

  • Model trained on prosody + intonation. Knows "...send a message to" sounds incomplete (rising tone, dangling preposition)
  • "Send the report." sounds complete (falling tone) → end turn even at 300ms silence
  • Outputs probability 0–1 of "turn complete"
  • Falls back to silence threshold if model uncertain
  • Hard cap (stop_secs) prevents infinite wait

2. Architecture

[ Audio chunks (16-bit PCM) ] │ ▼ ┌────────────────┐ │ VAD Silero │ is_speech: bool per chunk └────────┬───────┘ │ ▼ ┌───────────────────────────────────────┐ │ SmartTurnAnalyzer.append_audio() │ │ ─ buffer (timestamp, float32) │ │ ─ track silence_ms │ │ ─ if silence > stop_secs (3s): │ │ → COMPLETE (hard fallback) │ └───────────────────┬───────────────────┘ │ (triggered by VAD turn boundary │ OR scheduler — see step 4) ▼ ┌───────────────────────────────────────┐ │ analyze_end_of_turn() [async] │ │ ─ extract last 8s window │ │ ─ resample to 16 kHz │ │ ─ Whisper feature extractor │ │ ─ ONNX inference (sigmoid) │ │ ─ probability > 0.5 → COMPLETE │ └───────────────────┬───────────────────┘ │ ▼ COMPLETE / INCOMPLETE │ │ ▼ ▼ end turn keep listening
Two-layer safety: hard silence threshold (3s) is the floor. ML model can end turn earlier with high confidence, but never delays past stop_secs. If model fails/timeouts → fall back to silence rule.

3. Core data structures

Params (defaults from base_smart_turn.py)

STOP_SECS         = 3      # max silence before forcing end of turn
PRE_SPEECH_MS     = 500    # audio kept before speech starts (carries lead-in)
MAX_DURATION_SECS = 8      # max audio window sent to model

State machine

class EndOfTurnState(Enum):
    COMPLETE   = 1   # user done; fire LLM
    INCOMPLETE = 2   # user still speaking or just paused

Internal state per analyzer

self._audio_buffer       : list[(timestamp, float32_chunk)]  # rolling
self._speech_triggered   : bool                               # ever heard speech?
self._silence_ms         : float                              # accumulated silence
self._speech_start_time  : float                              # epoch sec
self._executor           : ThreadPoolExecutor(max_workers=1)  # model inference

4. Algorithm walkthrough

1

Chunk arrives → append_audio(buffer, is_speech)

Convert int16 → float32 normalized [-1, 1]. Append (time.time(), float_chunk) to ring buffer.

2

If is_speech=True

Reset silence_ms = 0. Set speech_triggered = True. Stamp speech_start_time if first speech ever.

3

If is_speech=False and speech was triggered

Compute chunk duration: len(int16_chunk) / (sample_rate / 1000). Add to silence_ms. If silence_ms ≥ stop_secs * 1000 → return COMPLETE immediately. No model call needed; user is clearly silent.

4

Caller decides to analyze (e.g. VAD says "user stopped")

Calls await analyzer.analyze_end_of_turn(). This dispatches model inference to executor thread (model may take 50–200ms).

5

Window extraction

Pull audio from speech_start_time - pre_speech_ms to now. Concatenate float32 chunks. If > max_duration_secs, keep only last 8 seconds. The model needs context — too short = bad guess.

6

Resample + feature extract

Resample to 16 kHz with soxr (VHQ quality) if pipeline rate differs. Feed Whisper feature extractor (mel-spectrogram, chunk_length=8). Pad with zeros at start (not end!) to exactly 8s.

7

ONNX inference

Run session.run(None, {"input_features": features}). Model is smart-turn-v3.2-cpu.onnx bundled in package. Sigmoid output ∈ [0, 1] = probability turn is complete.

8

Threshold + return

prediction = 1 if probability > 0.5 else 0. Return (state, TurnMetricsData) where metrics carry probability + e2e processing ms.

# Pad to 8s by prepending zeros (not appending!)
def truncate_or_pad(audio, n_seconds=8, sr=16000):
    max_samples = n_seconds * sr
    if len(audio) > max_samples:
        return audio[-max_samples:]
    elif len(audio) < max_samples:
        padding = max_samples - len(audio)
        return np.pad(audio, (padding, 0), mode="constant", constant_values=0)
    return audio

# Whisper feature extractor → mel spectrogram
inputs = self._feature_extractor(
    audio_array,
    sampling_rate=16000,
    return_tensors="np",
    padding="max_length",
    max_length=8 * 16000,
    truncation=True,
    do_normalize=True,
)
input_features = np.expand_dims(inputs.input_features.squeeze(0).astype(np.float32), axis=0)

outputs = self._session.run(None, {"input_features": input_features})

7. Why it matters for ai-gateway

Current pipeline pain points fixed by Smart Turn:

  • Babelcast S2S (real-time translation): user thinks mid-sentence → bot translates partial. Smart Turn waits for prosodic completion.
  • Meeting bots via Recall.ai: speakers in meetings have natural long pauses. Aggressive pauseMs creates fragmented translations.
  • Voice clone TTS conditioned on full utterance — needs complete turn before LLM call to avoid splitting context.
  • Ensemble STT race: cleaner turn boundaries = better consensus across providers.
Cost trade-off: ML inference per turn boundary (~50–200ms CPU). Adds < 200ms p95. Saves 1000ms+ of false-positive interrupts on natural speech. Net win.

// src/audio/turn/base-turn-analyzer.ts
export enum EndOfTurnState { COMPLETE = 1, INCOMPLETE = 2 }

export interface SmartTurnParams {
  stopSecs: number;        // 3
  preSpeechMs: number;     // 500
  maxDurationSecs: number; // 8
}

export interface TurnAnalyzer {
  appendAudio(pcm16: Int16Array, isSpeech: boolean): EndOfTurnState;
  analyzeEndOfTurn(): Promise<{ state: EndOfTurnState; probability: number }>;
  clear(): void;
}
// src/audio/turn/smart-turn-http.ts
export class HttpSmartTurnAnalyzer implements TurnAnalyzer {
  constructor(private url: string, private params: SmartTurnParams) {}

  appendAudio(pcm16: Int16Array, isSpeech: boolean): EndOfTurnState {
    // mirror Python state machine — silence accumulator + buffer
    // ...
    if (this.silenceMs >= this.params.stopSecs * 1000) {
      this.clear();
      return EndOfTurnState.COMPLETE;
    }
    return EndOfTurnState.INCOMPLETE;
  }

  async analyzeEndOfTurn() {
    const audio = this.extractWindow();        // last 8s, prepended zeros
    const resampled = await resampleTo16k(audio);
    const body = serializeFloat32(resampled);  // matches np.save format

    const ctrl = new AbortController();
    const timer = setTimeout(() => ctrl.abort(), this.params.stopSecs * 1000);
    try {
      const r = await fetch(this.url, {
        method: 'POST',
        headers: { 'Content-Type': 'application/octet-stream' },
        body,
        signal: ctrl.signal,
      });
      const json = await r.json();
      return {
        state: json.prediction === 1 ? EndOfTurnState.COMPLETE : EndOfTurnState.INCOMPLETE,
        probability: json.probability,
      };
    } catch {
      // timeout/error → conservative: close turn (fall back to silence rule)
      return { state: EndOfTurnState.COMPLETE, probability: 0 };
    } finally {
      clearTimeout(timer);
    }
  }
}

Wiring into /v1/stt/stream

// server/routes/streaming-stt.ts (sketch)
const vad = new SileroVAD();
const turn = new HttpSmartTurnAnalyzer(
  'http://gpu-pod:8001/predict',
  { stopSecs: 3, preSpeechMs: 500, maxDurationSecs: 8 },
);

ws.on('message', async (chunk: Buffer) => {
  const pcm16 = new Int16Array(chunk.buffer);
  const isSpeech = vad.detect(pcm16);
  const fastState = turn.appendAudio(pcm16, isSpeech);

  if (fastState === EndOfTurnState.COMPLETE) {
    fireLLMPipeline(buffered);            // hard silence cutoff
    return;
  }

  if (vad.justStopped()) {                // optional ML check
    const { state, probability } = await turn.analyzeEndOfTurn();
    if (state === EndOfTurnState.COMPLETE) {
      logger.info({ probability }, 'smart turn end');
      fireLLMPipeline(buffered);
    }
  }
});

9. Tuning notes

  • Threshold 0.5 is conservative: lower it (e.g. 0.4) to end turns faster — risks more false-completes.
  • pre_speech_ms=500: model needs lead-in for prosody context. Don't go below 300ms.
  • max_duration_secs=8: hard limit. Long monologues lose early context (truncated to last 8s).
  • Sample rate: model trained on 16 kHz. Resample everything else (use soxr VHQ for quality, linear for speed).
  • VAD coupling: smart turn runs on top of VAD. Bad VAD → garbage in. Use Silero, not amplitude threshold.
  • Model variant: v3.2-cpu bundled. GPU model variant exists for HTTP service — ~5x faster, batchable.
  • Logging: env PIPECAT_SMART_TURN_LOG_DATA=1 dumps audio segments for offline review (with _complete / _incomplete suffix).
