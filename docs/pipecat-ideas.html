Architectural Patterns to Steal

Concepts to formalize in ai-gateway. These are the load-bearing ideas.

coreadopt

Frame-based pipeline (downstream/upstream)

src/pipecat/frames/frames.py · ~100 frame types

All data flows as Frame objects through FrameProcessor chain. Downstream = data path. Upstream = errors/acks. Each frame has id, name, pts (presentation timestamp ns), metadata, transport_source/dest.

Apply: formalize current ad-hoc pipeline in src/streaming-stt.ts + speech route. Frame abstraction = clean interruption + barge-in support.
coreadopt

Smart Turn detection (ML end-of-turn) — deep dive →

src/pipecat/audio/turn/smart_turn/ · v2 + v3 + CoreML + HTTP

ML model decides when user finished speaking. Beats silence-threshold pauseMs. Params: stop_secs=3, pre_speech_ms=500, max_duration_secs=8. Pluggable via BaseSmartTurn. ONNX 16 kHz + Whisper feature extractor.

Apply: drop-in replacement for current pauseMs in /v1/stt/stream + WS pipeline. HTTP variant = call hosted model. See architecture + TS port plan →

core

Interruption handling protocol

CLAUDE.md: InterruptionFrame + asyncio.Event

InterruptionFrame carries asyncio.Event set when frame reaches sink. Processor that stops it MUST call frame.complete(). Uninterruptible: EndFrame, StopFrame.

Apply: barge-in for /v1/speech/ws. Currently no clean cancel of in-flight LLM/TTS. Critical for production voice agents.
obs

Observer pattern (non-invasive)

src/pipecat/observers/ · base_observer + turn_tracking + user_bot_latency + startup_timing

Monitor frame flow without modifying pipeline. on_process_frame + on_push_frame hooks. Built-in: TurnTrackingObserver, UserBotLatencyObserver, StartupTimingObserver.

Apply: replace scattered metric calls with observer pattern. Plugs into existing Langfuse + Prometheus.
infra

TaskManager (auto-cleanup)

CLAUDE.md: self.create_task(coro, name)

Never raw asyncio.create_task. TaskManager tracks + cleans on processor shutdown. cancel_task(task, timeout) for cancellation.

Apply: server/* lifecycle. Many leaked Promises in current GPU monitor + autoscaler loops. Bun-native equivalent.
protocol

RTVI protocol

src/pipecat/processors/frameworks/rtvi.py

Real-Time Voice Interface protocol bridging clients + pipeline. Standardized messages: text input, audio, function call results, user/bot speaking events, transcriptions, LLM/TTS lifecycle, metrics, audio levels.

Apply: standardize /v1/speech/ws wire format. Free client SDKs (JS/React/iOS/Android/C++/ESP32) via RTVI compatibility.

What NOT to Take

Pipecat is Python framework with strong opinions. Avoid wholesale port.

  • asyncio idioms — Bun has different concurrency model. Adapt patterns, don't port.
  • Frame protobuf wire format — over-engineered for our scope. JSON + binary opcodes simpler.
  • Daily.co coupling — Daily is owner; some patterns favor their infra.
  • Heavy class hierarchy — TS/Bun stack prefers composition. BaseObject → events tree → tasks tree is Python-flavored.
  • uv tooling — we use Bun. Pre-commit + ruff don't apply.
