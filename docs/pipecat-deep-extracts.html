Pipecat — Round 2: Deep Extracts

Walked deeper into /tmp/pipecat-research/src/pipecat/. Found 8 entire categories of useful code beyond the high-level steal list. Telephony codecs, audio mixers, IVR navigation, voicemail detection, pattern pair aggregator, 7 user-turn-start strategies, full RTVI protocol, OpenTelemetry tracing.

1. Telephony stack net-new feature

ai-gateway has zero telephony today. Pipecat ships full Twilio/Plivo/Vonage/Telnyx/Exotel/Genesys integration with μ-law codec, hangup automation, and DTMF handling. Total ~2400 LOC across 6 serializers + base.

port mecodec

μ-law ↔ PCM codec

audio/utils.py · pcm_to_ulaw / ulaw_to_pcm

Async helpers convert PCM ↔ μ-law (G.711) with optional resample. Telephony is fixed 8kHz μ-law; ai-gateway pipeline 16kHz PCM. Need both directions.

Apply: Bun helper using audioop equivalent (port via lookup table — μ-law is byte-mapped, no math). ~40 LOC.
copy structure

TwilioFrameSerializer (276 LOC)

serializers/twilio.py

Handles: Twilio Media Streams WS protocol, base64 audio frames, DTMF events, auto-hangup via Twilio REST API on EndFrame. Validates account_sid/auth_token/region/edge.

Apply: reference for new server/telephony/twilio.ts. Wire to existing /v1/speech/ws with format adapter.
copy structure

Plivo / Vonage / Telnyx / Exotel / Genesys

serializers/{plivo,vonage,telnyx,exotel,genesys}.py

252 / 184 / 288 / 167 / 962 LOC each. Each carrier has slightly different WS protocol but same shape: connect → audio frames → DTMF → hangup.

Apply: start with Twilio (largest market). Genesys is enterprise contact-center oriented (962 LOC = most complex). Plivo simplest path.
unique feature

IVR Navigator (extension)

extensions/ivr/ivr_navigator.py

LLM-driven phone tree navigation. Listens to IVR prompts ("Press 1 for sales..."), feeds to LLM with goal context, generates DTMF tones to navigate. Uses OutputDTMFUrgentFrame + PatternPairAggregator.

Apply: outbound call automation product feature. Requires telephony stack first.
unique feature

Voicemail Detector

extensions/voicemail/voicemail_detector.py

Parallel pipeline classifies if outbound call hit voicemail vs human. Critical for outbound dialers — different prompts based on result.

Apply: outbound calling SaaS feature. Drop-in once telephony works.
DTMF

DTMF tone library

audio/dtmf/ · dtmf-{0..9,*,#}.wav + types.py

12 pre-recorded DTMF tones for keypad output. KeypadEntry enum maps digits to tones.

Apply: copy 12 wavs to dockers/<tts>/assets/dtmf/. Mix with audio output for IVR.

2. Audio processing utilities port these

Audio helpers ai-gateway lacks: noise filters, mixers, volume meters, multi-backend resamplers.

3 resampler implementations

audio/resamplers/{soxr,soxr_stream,resampy}_resampler.py

SOXR (best quality, slow), SOXR stream (chunk-by-chunk for live), Resampy (numpy-based, decent). Pipecat uses SOXR as default.

Apply: Bun uses soxr-wasm for browser, native libsoxr via FFI for server. Stream variant essential for WS.
copy

Audio mixer (background music)

audio/mixers/soundfile_mixer.py

Mixes background WAV file into output stream at configurable gain. Loops automatically.

Apply: hold-music for telephony, ambient sound for voice agents.
noise filter

5 noise filter providers

audio/filters/{aic,koala,krisp_viva,rnnoise}_filter.py

RNNoise = OSS, free, recurrent NN. Krisp Viva = commercial, best. Koala = Picovoice, on-device. AIC = acoustic interference cancel.

Apply: RNNoise via WASM in browser (MIT licensed); Krisp for production. Cleans mic input before STT.
port

Volume calc (pyloudnorm)

audio/utils.py · calculate_audio_volume

ITU-R BS.1770-4 loudness standard. Returns LUFS. SPEAKING_THRESHOLD = 20 constant — speech usually ±500 to ±5000.

Apply: volume meter UI for /v1/speech/ws clients. Detect "user too quiet/loud".
stereo

Stereo interleave + mix

audio/utils.py · interleave_stereo_audio + mix_audio

Bot voice on right channel, user on left — useful for recording / debugging conversations as 2-channel WAV.

Apply: bot recording feature — save sessions as stereo WAV for QA.

3. Pipeline composition patterns arch ideas

Beyond ParallelPipeline already noted. Pipecat has runtime hot-swap of services + sync parallel + service routing.

A/B testing

ServiceSwitcher / LLMSwitcher

pipeline/{service_switcher,llm_switcher}.py

Hot-swap LLM/STT/TTS provider mid-conversation without restart. Different model per turn. Useful for: cheap LLM for simple turns + expensive for complex; A/B testing in production.

Apply: formalize ai-gateway's percentage-routing feature. Decide per-frame, not per-session.
sync

SyncParallelPipeline

pipeline/sync_parallel_pipeline.py

Like ParallelPipeline but waits for ALL branches to complete before passing downstream. Useful: ensemble STT race where you wait for slowest.

Apply: ensemble STT with consensus voting (vs current "first wins").
obs

TaskObserver

pipeline/task_observer.py

Observer pattern at pipeline-task level. Monitors task lifecycle: start, frame counts, errors, shutdown.

Apply: add to server/ws-server.ts session lifecycle metrics.
infra

FrameQueue (with backpressure)

utils/frame_queue.py

Bounded async queue with size limits + frame priority. Drops/rejects on overflow.

Apply: WebSocket backpressure — current /v1/speech/ws has no bounded queue → memory leak risk under load.

4. LLM Context management conversation quality

Pipecat treats LLM context as a first-class object with summarization, gating, and pattern-pair extraction.

huge value

LLMContextSummarizer (auto-compaction)

processors/aggregators/llm_context_summarizer.py + utils/context/llm_context_summarization.py

Auto-summarizes old conversation turns when context approaches token limit. Configurable threshold + summary prompt. Keeps recent N turns verbatim, condenses earlier into bullet summary.

Apply: long-running meeting bots overflow context fast. Critical missing piece.
unique

PatternPairAggregator

utils/text/pattern_pair_aggregator.py

Strips delimited content from streaming LLM output. Extract <thinking>...</thinking> blocks (reasoning models), pull function call args, separate inner monologue from spoken response. Configurable: REMOVE / KEEP / FORWARD.

Apply: handle reasoning model outputs without sending thinking tokens to TTS. Already needed for Claude/o1 integration.
flow

GatedLLMContext

processors/aggregators/gated_llm_context.py

Delays LLM context updates until external signal. Use case: pause inserting user's mid-thought into context until VAD confirms turn end.

Apply: Smart Turn integration — only commit to LLM context when COMPLETE confirmed.
per-provider

LLM-specific context aggregators

processors/aggregators/llm_response.py + adapters/services/*_adapter.py

Per-LLM message format adapter. Anthropic (system param + content blocks), OpenAI (messages array), Gemini (parts), Bedrock, Mistral, Perplexity, Inworld realtime, OpenAI realtime, AWS Nova Sonic, Grok realtime.

Apply: reference for ai-gateway provider abstraction. Some quirks (Anthropic system param) easy to miss.
streaming

SentenceAggregator

processors/aggregators/sentence.py

Buffers LLM streaming tokens until sentence end (`.` `?` `!`), then emits full sentence. Drives TTS chunking — synthesize per sentence not per token.

Apply: port to src/streaming-stt.ts overlap layer. ~40 LOC. Existing token→TTS overlap probably has this implicitly.

5. User Turn Start strategies 7 variants

Different ways to detect when user starts speaking. Composable — pick or stack.

StrategyTriggerUse case
VADUserTurnStartStrategySilero VAD says speechDefault — works with any audio source
WakePhraseUserTurnStartStrategyHotword "hey computer"Always-on assistant, ignore until wake
MinWordsUserTurnStartStrategy≥ N words transcribedFilter "uh"/"um"/single-syllable noise

composable

Stacking strategies

Strategies emit UserStartedSpeakingFrame. Pipeline can require ALL or ANY. Wake-phrase + min-words = hotword detection that ignores accidental "ok google" with no real follow-up.

Apply: ai-gateway today only has VAD-based heuristics. Adopting strategy pattern unlocks PTT, wake-word, transcript-driven modes.

7. OpenTelemetry tracing production observability

Service decorators + setup utilities. Optional dep — graceful skip if not installed.

port

Service decorators

utils/tracing/service_decorators.py

Decorators wrap STT/LLM/TTS calls in OTel spans. Auto-add: model name, latency, token counts, sample rates, success/error status.

Apply: decorate ai-gateway provider methods. Span attributes drive Langfuse + any OTel-compatible backend.
turn

TurnTraceObserver

utils/tracing/turn_trace_observer.py

Per-conversation-turn OTel span. Child spans: STT, LLM, TTS, TTFAC. Parent links to conversation.

Apply: conversation tracing in Langfuse — already integrated, this gives the right span hierarchy.
runtime

TracingContext

utils/tracing/tracing_context.py

Thread-local context for current trace ID. Propagates through async tasks via contextvars. Link external requests to internal spans.

Apply: Bun has AsyncLocalStorage. Same pattern. Propagate trace IDs across handler → provider → response.

8. Frame filters composable middleware

5 small reusable filter processors. Each ~50-100 LOC.

FrameFilter

processors/filters/frame_filter.py

Pass only listed frame types downstream. Block all others.

FunctionFilter

processors/filters/function_filter.py

Predicate function decides per-frame. Async-safe.

IdentityFilter

processors/filters/identity_filter.py

Pass-through. Used as observation point or for testing.

NullFilter

processors/filters/null_filter.py

Drops everything. Pipeline terminator for testing.

WakeNotifierFilter

processors/filters/wake_notifier_filter.py

Emits notification when wake phrase detected. Used by wake-phrase strategy.

IdleFrameProcessor

processors/idle_frame_processor.py

Triggers callback after N seconds of no frames. Auto-greet user, ping for response, terminate idle session.

11. What's worth NOT taking from round 2

  • Krisp filters — commercial license, expensive. Use RNNoise instead.
  • GStreamer processor — heavy native dep. Bun + soxr-wasm cleaner.
  • Genesys serializer — 962 LOC for niche enterprise contact-center protocol. Skip until customer asks.
  • resampy — slower than SOXR, redundant.
  • WakeCheckFilter (deprecated) — use new WakePhraseUserTurnStartStrategy.
  • Pipecat BaseObject events — heavy class hierarchy, doesn't fit Bun composition style.
